# CS320-Software-Test-Automation-QA
How can I ensure that my code, program, or software is functional and secure?
To ensure that my code, program, or software is functional and secure is to test it thoroughly and test the bounds of the input(s). Running it through tests, and ensuring that it meets every requirement will prepare it to be functional and secure.
How do I interpret user needs and incorporate them into a program?
I interpret user needs and incorporate them into a program by making sure firstly, that I understand them fully. Then, I would make a list of all of the user's needs and making sure as I code the program that every need is met. 
How do I approach designing software?
I approach designing software by making a list of all the requirements for the program first. Then, as I review the requirements, I ensure that there is no overlapping with what is required. Once that is finished, I start coding the software, and testing after every feature is finished to ensure that it meets the requirements. After all coding and testing is completed, I send it off for completion.
